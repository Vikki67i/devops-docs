# devops-docs

Учебный репозиторий практической работы № 9 по Pylint, MkDocs, GitHub Actions и GitHub Pages.

- Исходники документации хранятся в `docs/`.
- Настройки сайта находятся в `mkdocs.yml`.
- Проверка кода описывается в `.github/workflows/quality.yml`.
- Публикация сайта описывается в `.github/workflows/pages.yml`.

Каталог `site/` создаётся при сборке сайта и не хранится в Git.
